01 / COHERENCE

时间瓦片，把七张图绑成一个批次

一个视口由 1～2 个等长时间瓦片拼成。七张通道图必须整批生成、整批命中、整批发布，顶部时间轴跟随同一次切换；当前、前进方向、反方向邻居按三档优先级预取。

TILE KEY / viewMode × tileIndex × dataVersion × size × style

02 / RESILIENCE

未命中，也不让画面闪白

缓存未命中时保留最后一张完整有效帧，隐藏旧十字线与 Tooltip；后台优先渲染目标批次。模式、数据或样式变化会推进 epoch，让晚到的旧结果直接作废。64 MiB 预算按完整批次淘汰，在屏批次受保护，长时间拖拽下 GDI 句柄保持稳定。

HELD FRAME → PREFETCH → ATOMIC SWAP / 64 MiB LRU
